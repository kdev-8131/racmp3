# RacMp3

Convertisseur MP4 vers MP3 (Electron + React + ffmpeg).

## Développement

```bash
npm install
npm run dev
```

## Construire l'exe

```bash
npm run dist
```

Les exe (installateur et portable) sont générés dans `release/`.
Copie les deux exe (installateur et portable) dans `download/` pour que la page `download/index.html` les propose au téléchargement.
